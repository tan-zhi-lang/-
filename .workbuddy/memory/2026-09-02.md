## Vela AI API 文档门户
- 产出：`D:\-\docs-site\index.html`（单文件，零外部依赖，~80KB）
- 结构：三栏（可折叠侧边导航 / 端点文档 / 右侧代码示例面板），右栏在 ≤1240px 折叠到文档下方，≤960px 侧栏变抽屉
- 主题：CSS 变量双主题，默认深色，localStorage 键 `vela-theme`
- 语法高亮：自写 tokenizer（python/javascript/bash/json），规则数组 + 单一合并正则；**所有 inner group 必须写成 `(?:...)`**，否则分组索引错位导致 `rules[i-1]` 为 undefined
- 代码块用 `<script type="text/plain">` 承载源码，避免 HTML 转义问题；JS 读取 textContent 后注入 `<pre><code>`
- 其他交互：IntersectionObserver 滚动高亮、`/` 聚焦搜索、剪贴板复制（带 execCommand 回退）
