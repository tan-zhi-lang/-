## RipperDemon 跳楼 Bug 修复（已改代码，编译通过）
- 文件：actors/mobs/RipperDemon.java。
- 根因：leapVictim==null 分支直接 endPos=leapPos，未校验落点，跳跃终点可能是 pit（深渊）/solid/被占；bouncepos 循环遇到第一个候选就 break，且 leapPos+i 无越界检查。
- 新增 可落地(cell)：insideMap && !pit && !solid && passable && findChar==null；新增 最近落点(from)：8方向取距 pos 最近的可落地格。
- 落地逻辑：victim 分支用 最近落点；非 victim 分支先判 可落地(leapPos)，否则退到相邻落点，都不行则 leapPos=-1 取消跳跃。
- 选点阶段（Hunting 后段）新增过滤：targetPos 必须 insideMap && !pit && !solid && passable，否则回退 enemy.pos；且 pit 目标不发起跳跃。
- 存档恢复的 leapPos 加范围校验（<0 或 >=length 则取消）。
- 编译验证命令：`cd /d/- && ./gradlew :core:compileJava`（约 6 分钟，无 Android 变体任务）。
