
## 2026-09-02 未来空间器物品消失bug
- 根因：onSelect 存入 Statistics.itemN 的是背包内原对象而非 detach 返回值，同堆叠二次放入导致两槽共用同一对象。
- 已按用户要求将 9 处 isEquipped/doUnequip/detach 分支统一改为 item.detachAll(backpack)，detachAll 会将整个物品从背包移除，引用重复问题随之消除。
- 跨存档刷物品：Statistics.reset() 与 restoreFromBundle() 均未清空 item1~item9 静态字段，静态残留被写入其他存档。
- 修复：Statistics.java reset() 增加 item1~item9=null；restoreFromBundle() 恢复前先置 null 再按 contains 恢复。
- 改为全局互通：item1~9 不再随各存档序列化，改为 未来空间器.saveGlobal()/loadGlobal() 读写全局文件 未来空间器.dat；Dungeon.saveGame 写入、loadGame/reset 读取。物品全局唯一，互通且不可复制。
